Estadisticas

Estadisticas de musica del plugin. La base de datos SQLite es propia y no modifica la base de datos de Jellyfin. Solo se registran reproducciones de audio (umbral 20s).

Top 25 - Mas escuchadas

Las consultas excluyen el periodo actual (semana/mes/ano en curso).

Bottom 25 - Menos escuchadas

Incluye canciones/artista/albumes/generos con 0 reproducciones en el periodo. El desempate es por menos reproducciones totales historicas, luego alfabetico.

Listas de reproduccion programadas

Las listas programadas se regeneran y reemplazan (misma playlist) en la frecuencia indicada. La hora es hora local del servidor.

Debug y pruebas

Herramientas para verificar que el plugin funciona correctamente sin tener que esperar 2 semanas a que se llenen las ventanas temporales con reproducciones reales.

Como probar el plugin

  1. Pulsa Actualizar estado para ver el estado actual de la BD del plugin.
  2. Si todas las ventanas muestran 0 reproducciones, pulsa Inyectar datos de prueba. Se crearan 50 canciones sinteticas con ~1500 reproducciones distribuidas en todas las ventanas temporales.
  3. Vuelve a la pestana Top 25 o Bottom 25 y haz consultas. Deberian aparecer resultados en todas las ventanas.
  4. Para probar con datos reales: reproduce canciones en Jellyfin (al menos 20 segundos cada una) y vuelve a la pestana Debug para ver como aumentan los contadores por ventana.
  5. Cuando termines las pruebas, pulsa Borrar todos los datos para limpiar la BD. Las listas programadas se conservan.

Nota: las canciones sinteticas usan ItemIds aleatorios que NO existen en Jellyfin. Las consultas Top/Bottom funcionaran perfectamente, pero si intentas crear una playlist desde datos sinteticos, la playlist estara vacia (las canciones no se pueden resolver en la biblioteca). Para probar la creacion real de playlists, debes reproducir musica real primero.
