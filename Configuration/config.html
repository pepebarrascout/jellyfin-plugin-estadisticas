Estadísticas de música del plugin. La base de datos SQLite es propia y no modifica la base de datos de Jellyfin. Sólo se registran reproducciones de audio (umbral 20s).

Top 25 — Más escuchadas

Las consultas excluyen el periodo actual (semana/mes/año en curso).

Bottom 25 — Menos escuchadas

Incluye canciones/artistas/álbumes/géneros con 0 reproducciones en el periodo. El desempate es por menos reproducciones totales históricas, luego alfabético.

Debug y pruebas

Herramientas para verificar que el plugin funciona correctamente sin tener que esperar 2 semanas a que se llenen las ventanas temporales con reproducciones reales.

Cómo probar el plugin

  1. Pulsa Actualizar estado para ver el estado actual de la BD del plugin.
  2. Si todas las ventanas muestran 0 reproducciones, pulsa Inyectar datos de prueba. Se crearán 50 canciones sintéticas con ~1500 reproducciones distribuidas en todas las ventanas temporales.
  3. Vuelve a la pestaña Top 25 o Bottom 25 y haz consultas. Deberían aparecer resultados en todas las ventanas.
  4. Para probar con datos reales: reproduce canciones en Jellyfin (al menos 20 segundos cada una) y vuelve a la pestaña Debug para ver cómo aumentan los contadores por ventana.
  5. Cuando termines las pruebas, pulsa Borrar todos los datos para limpiar la BD. Las listas programadas se conservan.
Nota: las canciones sintéticas usan ItemIds aleatorios que NO existen en Jellyfin. Las consultas Top/Bottom funcionarán perfectamente, pero si intentas crear una playlist desde datos sintéticos, la playlist estará vacía (las canciones no se pueden resolver en la biblioteca). Para probar la creación real de playlists, debes reproducir música real primero.
